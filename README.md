# Finish the Word

Онлайн-игра в слова для двух и более игроков. Игра выбирает случайную букву, первый игрок называет слово на неё, следующий называет слово на последнюю букву предыдущего. Не успел за время хода: минус жизнь. Побеждает последний, у кого остались жизни.

Слова английские, от 3 букв, без повторов. Словарь встроен в страницу (около 112 тысяч слов).

## Как играть через интернет

1. Открой сайт, введи имя и нажми «Создать комнату». Ты получишь код из 4 символов.
2. Нажми «Скопировать ссылку» и отправь её другу (или назови код).
3. Друг открывает ссылку, вводит имя и нажимает «Войти».
4. Любой из вас нажимает «Начать игру».

Комната живёт, пока страница открыта у создателя. Если создатель закроет страницу, комната закроется для всех.

## Как это работает

Сервера у игры нет. Создатель комнаты хранит состояние игры у себя в браузере, остальные игроки подключаются к нему напрямую через WebRTC. Для знакомства игроков используется бесплатный публичный сервис [PeerJS](https://peerjs.com). Если игроки в сложных сетях (некоторые мобильные операторы) не могут соединиться, понадобится небольшой сервер-посредник.

## Как выложить на GitHub Pages

1. На github.com нажми New repository, назови его `finish-the-word`, выбери Public и создай.
2. В репозитории нажми Add file, затем Upload files, перетащи `index.html` и `README.md`, нажми Commit changes.
3. Открой Settings, затем Pages. В разделе Source выбери Deploy from a branch, ветку `main` и папку `/ (root)`, нажми Save.
4. Через минуту-две игра будет доступна по адресу `https://ТВОЁ-ИМЯ.github.io/finish-the-word/`.

## Без интернета

Если открыть `index.html` без доступа к PeerJS, игра переключается в автономный режим: можно играть вдвоём на одном экране.
